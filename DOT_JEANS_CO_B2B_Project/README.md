## Description
B2B Wholesale portal for DOT JEANS CO.

- `assets/images/`: Store brand logos, product banners, and catalog images.
- `css/`: Modular stylesheets (`colours.css`, `typography.css`, and `style.css`).
- `js/`: Application logic, WhatsApp inquiry routing, and widget management.
- `widgets/`: Reusable HTML component templates.
